**A full-stack Dart application powered by Flutter and Serverpod that generates tailored culinary recipes from your available kitchen ingredients using Large Language Models.**

</div>

---

## ✨ Key Features

- 🤖 **AI-Powered Recipe Generation:** Enter the ingredients in your fridge and let the LLM generate structured recipes, cooking times, and step-by-step instructions.
- ⚡ **End-to-End Type-Safe Dart:** Shared serialization models and auto-generated client-server RPC protocols between magic_recipe_server, magic_recipe_client, and magic_recipe_flutter.
- 🗄️ **PostgreSQL & Redis Caching:** Built on Serverpod's ORM with containerized PostgreSQL and Redis instances.

## 📂 Monorepo Structure

- magic_recipe_server/ — Serverpod backend server, LLM endpoints, and database migrations
- magic_recipe_client/ — Auto-generated type-safe Dart client library
- magic_recipe_flutter/ — Cross-platform Flutter mobile & web application
